# v0.1.0

Released on 17 November 2026. This release contains the evidence ledger, frozen
receipts, result summaries, static audits, vector figures, a no-data validator,
ISPRS preparation and receipt execution commands, and archived source protocols
for OEM/LoveDA v2 and v4f. It accompanies the IGARSS 2027 manuscript *Do
Acquisition-Level Structured Query Rules Consistently Help? A Controlled
Assessment in Cross-Region Remote-Sensing Segmentation*.

The release includes a normalized 1062-row score file, a 228-cell
post-completion descriptive consistency summary, fixed-control sensitivity
results, and their builder/tests. The identical tagged archive is preserved at
Zenodo under DOI `10.5281/zenodo.24137437`.

The release intentionally excludes original remote-sensing data, labels, model
weights, checkpoints, and the third-party DeepLab source tree. Its scientific
scope is conditional: the stored comparisons do not show a consistent advantage
for the tested structured selection rules over the stated controls.
