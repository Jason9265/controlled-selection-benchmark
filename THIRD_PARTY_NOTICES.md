# Third-party material and exclusions

This release contains only project-authored code, frozen metadata, audit records,
result summaries, and derived figures.

It does **not** contain OpenEarthMap, LoveDA, ISPRS Potsdam/Vaihingen images or
labels; ImageNet ResNet-101 weights; DeepLab checkpoints; adapted model weights;
or the VainF DeepLab source tree. Obtain each item from its official source and
follow its own terms.

The ISPRS execution path expects the MIT-licensed VainF/DeepLabV3Plus-Pytorch
repository at commit `4e1087de98bc49d55b9239ae92810ef7368660db`. The source archive
used for the recorded experiments had SHA-256
`68259425a5f37bfc7784f5378466cb848ef82d3ff04a6b5167a5699d0b53e2fc`.
