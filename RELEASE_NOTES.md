# v0.1.0

Released on 11 November 2026. This release contains the evidence ledger, frozen
receipts, result summaries, static audits, vector figures, a no-data validator,
ISPRS preparation and receipt execution commands, and archived source protocols
for OEM/LoveDA v2 and v4f. It accompanies the IGARSS 2027 manuscript *When Do
Structured Query Rules Help? A Controlled Empirical Assessment of Selection
Strategies for Cross-Region Remote-Sensing Segmentation*.

The release intentionally excludes original remote-sensing data, labels, model
weights, checkpoints, and the third-party DeepLab source tree. Its scientific
scope is conditional: the stored comparisons do not show a consistent advantage
for the tested structured selection rules over the stated controls.
